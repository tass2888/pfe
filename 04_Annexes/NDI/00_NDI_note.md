# Neck Disability Index (NDI)

- Utiliser la version officielle validée (Vernon & Mior, 1991) ; ne pas joindre de scan copyrighté dans le mémoire sans autorisation. Citer la source et indiquer : « questionnaire fourni aux patients lors des évaluations ».
- 10 items (douleur, vie quotidienne, port de charges, lecture, céphalée, concentration, travail, conduite, sommeil, loisirs), cotés 0–5.
- Score brut /50 → pourcentage = (score / 50) × 100.
- Interprétation usuelle : 0–8 % absence de handicap ; 9–20 % léger ; 21–30 % modéré ; 31–40 % sévère ; > 40 % complet.
- MCID discuté dans la littérature : environ 5 points (certains auteurs 7–8). À préciser dans la méthodologie.
- Traduction arabe : à faire valider (traduction inverse) si utilisée.
