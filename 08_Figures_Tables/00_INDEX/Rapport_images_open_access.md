## Règles d'utilisation

1. **CC BY 4.0 / 3.0** : citer l'auteur, le titre, la licence et l'URL. Autorise les modifications.
2. **CC BY-SA 3.0 / 4.0** : mêmes obligations **plus** partage à l'identique si l'image est modifiée. Préférer une reproduction sans modification ou prévoir une mention « adaptée de ».
3. **CC0 / domaine public** : aucune obligation légale, mais la courtoisie académique reste recommandée.
4. **Ne pas présenter une image de soutien partiel comme une démonstration technique.** Les figures 3.3, 3.4, 6.1–6.4 montrent l'anatomie, pas le geste de glisseur/tensionneur.
5. **Figures 7.2–7.4** : à générer exclusivement à partir des données réelles anonymisées. Aucune donnée inventée.
6. **Validation** : faire vérifier chaque image par le directeur de mémoire avant insertion définitive.
