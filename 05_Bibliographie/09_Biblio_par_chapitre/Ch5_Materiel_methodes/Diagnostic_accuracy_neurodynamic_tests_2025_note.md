## Points forts (highlights de l'article)
- Les tests neurodynamiques montrent une précision diagnostique suffisante pour les neuropathies du membre supérieur.
- Bonne précision diagnostique pour la radiculopathie cervicale.
- Utilité diagnostique limitée pour le syndrome du canal carpien.
- Le respect des critères de Nee améliore la spécificité du test utilisé.
- L'interprétation doit rester prudente.

## Résultats chiffrés à citer (chapitre 5 et discussion)
- 12 études incluses.
- Neuropathies : LR+ = 1,65 ; LR− = 0,57.
- Radiculopathie cervicale : LR+ = 2,0 ; LR− = 0,47.
- Canal carpien : LR+ = 1,45 ; LR− = 0,66 ; AUC = 0,62.
- **ULNT2A** : meilleure précision globale (AUC = 0,76 ; LR+ = 2,59 ; LR− = 0,42 pour la radiculopathie cervicale).
- **ULNT3** : meilleure spécificité (0,92 ; LR+ = 7 ; LR− = 0,48).
- Méta-régression : les manœuvres de différenciation structurale améliorent significativement la performance (p = 0,002).
- Certitude des preuves : **très faible à modérée** (GRADE).

## Conclusion pour le mémoire
Un test neurodynamique positif ne suffit jamais à poser le diagnostic : l'intégrer dans un faisceau d'arguments cliniques (Spurling, distraction cervicale, rotation limitée, examen neurologique, imagerie si besoin), conformément aux recommandations de Wainner/Thoomes.
