## Règles d'utilisation

1. **Vancouver** : numéroter dans l'ordre d'apparition dans le texte, pas dans l'ordre alphabétique. La numérotation ci-dessus est un point de départ par chapitre ; renumeroter à la rédaction finale.
2. **Dates d'accès** : ajouter « Consulté le … » pour les pages web et bases de données.
3. **Langue** : traduire les titres français entre crochets si nécessaire selon le format UPSAT.
4. **Ne pas joindre** de PDF sous droit d'auteur dans le mémoire ; citer le DOI et signaler l'accès via UPSAT.
5. **NDI** : utiliser la version française validée, ne pas faire une traduction personnelle.
6. **Prudence interprétative** : la plupart des revues concluent à des bénéfices surtout à court terme, avec une certitude faible à très faible ; ne pas généraliser à la cervicalgie non spécifique.
